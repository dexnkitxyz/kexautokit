# KexAuto

โปรแกรมรับสินค้าอัตโนมัติจากบาร์โค้ด/QR code ในไฟล์ PDF สำหรับ Windows

โปรแกรมสามารถอ่านบาร์โค้ดจาก PDF แล้วพิมพ์ข้อมูลลงในหน้าต่างปลายทาง โดยรองรับ
การกำหนดลำดับการทำงาน การตรวจข้อความบนหน้าจอด้วย OCR และโหมดทดสอบก่อนยิงข้อมูลจริง

## วิธีใช้งานสำหรับผู้ใช้ทั่วไป

แนะนำให้ใช้ไฟล์ `kexauto.exe` จาก GitHub Releases เพราะไม่ต้องติดตั้ง Python หรือไลบรารี

1. ดาวน์โหลด `kexauto.exe` จากหน้า Releases
2. เปิดไฟล์ แล้วเลือกไฟล์ PDF
3. เปิด/โฟกัสหน้าต่างปลายทาง แล้วตรวจสอบค่าการตั้งค่า
4. ทดลองด้วย **Dry run (ทดสอบ ไม่พิมพ์จริง)** ก่อน
5. เมื่อพร้อม ให้กดเริ่มทำงานจริง

โปรแกรมจะค้นหา Poppler และ Tesseract ที่ฝังมากับตัวโปรแกรมให้อัตโนมัติ
หากไม่พบ สามารถระบุพาธได้จากหน้าตั้งค่า

เมื่อเปิดโปรแกรม ให้เข้าสู่ระบบด้วยบัญชีที่ผู้ดูแลสร้างไว้
ค่า Supabase Project URL และ publishable key ถูกกำหนดมาให้แล้วในโปรแกรม
สามารถตรวจสอบหรือเปลี่ยนค่าได้จาก **ตั้งค่า Supabase** บนหน้าเข้าสู่ระบบ
โปรแกรมจะจำการเข้าสู่ระบบอย่างปลอดภัยสำหรับบัญชี Windows ปัจจุบัน
หากต้องการล้าง session ให้เลือก **ไฟล์ > ออกจากระบบ** จากเมนูหลัก
ผู้ดูแลระบบจะเห็นปุ่ม **จัดการผู้ใช้** บนหน้าหลัก และโปรแกรมจะตรวจสอบ session กับเซิร์ฟเวอร์เป็นระยะ

## ระบบบัญชีผู้ใช้และการตั้งค่า Supabase

โปรแกรมจำ session แบบเข้ารหัสด้วย Windows DPAPI และผูกกับบัญชี Windows เครื่องเดิม
การเปิดโปรแกรมครั้งถัดไปจึงเข้าสู่ระบบให้อัตโนมัติ แต่ต้องเชื่อมต่ออินเทอร์เน็ต
โปรแกรมตรวจสอบสิทธิ์ทุก 30 วินาที และปิดเมื่อบัญชีถูกเพิกถอน

การตั้งค่า Supabase URL และ publishable key ถูกฝังไว้เป็นค่าเริ่มต้นแล้ว
ไม่ต้องกรอกซ้ำ หากต้องการเปลี่ยนค่าให้เลือก **ตั้งค่า Supabase** บนหน้าเข้าสู่ระบบ

### ติดตั้งระบบผู้ใช้บน Supabase

1. สร้าง Supabase project และติดตั้ง Node.js
2. เปิด PowerShell ในโฟลเดอร์โปรเจกต์ แล้วรัน:

   ```powershell
   npx supabase@latest login
   npx supabase@latest link --project-ref <project-ref>
   npx supabase@latest db push
   npx supabase@latest functions deploy manage-users
   ```

3. ใน Supabase Dashboard > Authentication > Users ให้สร้างบัญชีแรกสำหรับผู้ดูแล
4. เปิด SQL Editor แล้วเพิ่มบัญชีนั้นเป็นผู้ดูแล โดยแทนอีเมลในคำสั่ง:

   ```sql
   insert into public.app_admins (user_id)
   select id from auth.users where lower(email) = lower('admin@example.com')
   on conflict (user_id) do nothing;
   ```

5. เปิดโปรแกรมและเข้าสู่ระบบด้วยบัญชีผู้ดูแล จากนั้นใช้ปุ่ม **จัดการผู้ใช้**
   เพื่อสร้างบัญชีผู้ใช้หรือลบบัญชีที่ไม่ต้องการให้ใช้งาน

ห้ามนำ `service_role` key ไปใส่ในโปรแกรมหรือแจกจ่ายให้ผู้ใช้
Edge Function ใช้ key นี้ฝั่งเซิร์ฟเวอร์เท่านั้น
หากต้องการล้าง session ที่บันทึกไว้ ให้เลือก **ไฟล์ > ออกจากระบบ** จากเมนูหลัก
การปิดโปรแกรมตามปกติจะไม่ลบ session

> โปรแกรมควบคุมเมาส์และคีย์บอร์ดจริงเมื่อทำงาน หยุดฉุกเฉินได้โดยเลื่อนเมาส์ไปมุมซ้ายบนสุด
> (0,0) หรือกดปุ่มหยุดในโปรแกรม

โปรแกรมใช้ ZXing-C++ อ่านบาร์โค้ด/QR จาก PDF และแสดงเลขหน้า PDF ใน log เมื่อเลือกยิงย้อนจากหน้าท้าย
ปุ่มลัดเริ่ม/หยุด/ดำเนินการต่อ ตั้งค่าได้จากเมนู **ปุ่มลัด** (ค่าเริ่มต้น F6/F7/F8)
และข้อความปุ่มลัดบนแถบสถานะจะอัปเดตตามค่าที่ตั้งไว้
เมื่อครบจำนวนรอบที่ตั้งให้หยุดพัก โปรแกรมจะแจ้งเตือนด้วยเสียง
หน้าหลักใช้ UI แบบ Tkinter โดยตรง มีเมนูออกจากระบบ แถบเมนูด้านข้างที่พับย่อได้
และหัวข้อการทำงาน/Log ที่พับหรือขยายได้ พร้อมแสดงเวลาอ่าน PDF และเวลากรอกข้อมูล

## วิธีรันจาก source code

ต้องใช้ Windows และ Python 3.10 ขึ้นไป

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe auto_receive.py
```

หรือเปิด `setup_and_run.bat`

## การ build เป็นไฟล์ EXE

ตรวจสอบให้มีโฟลเดอร์ `poppler` และ `tesseract` อยู่ในโปรเจกต์ก่อน build

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\build_exe.bat
```

ไฟล์ที่ได้อยู่ที่ `dist_release\kexauto.exe`

## ไฟล์ตั้งค่าและข้อมูลผู้ใช้

การตั้งค่าและ cache จะเก็บแยกต่อผู้ใช้ที่:

```text
%LOCALAPPDATA%\KexAuto\
```

ข้อมูล session เข้ารหัสด้วย Windows DPAPI และผูกกับบัญชี Windows ปัจจุบัน
อย่าฝัง service-role key ในโปรแกรม; Edge Function ต้องใช้ secret ฝั่ง Supabase

จึงสามารถแจก `kexauto.exe` ให้ผู้ใช้อื่นได้โดยไม่ปะปนกับการตั้งค่าของผู้สร้าง

## การเผยแพร่เวอร์ชัน

โปรเจกต์มี GitHub Actions สำหรับสร้าง Release เมื่อ push tag รูปแบบ `vMAJOR.MINOR.PATCH`:

```powershell
git tag v1.0.3
git push origin v1.0.3
```

Workflow จะ build และแนบ `kexauto.exe` ใน GitHub Release ให้อัตโนมัติ
ปุ่ม **อัปเดต** ในโปรแกรมจะตรวจสอบ Release ล่าสุดและติดตั้งทับไฟล์เดิม
