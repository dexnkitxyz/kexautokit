# Kex Auto Kit

โปรแกรมช่วยอ่านบาร์โค้ด/QR จาก PDF แล้วส่งข้อมูลเข้าโปรแกรมปลายทางบน Windows

## ดาวน์โหลดไปใช้งาน

1. เปิดหน้า **Releases** ของโปรเจกต์
2. ดาวน์โหลดไฟล์ `auto_receive.exe` จาก Release ล่าสุด
3. วางไฟล์ไว้ในโฟลเดอร์ที่ต้องการ แล้วเปิดใช้งาน
4. ตั้งค่า PDF, หน้าต่างปลายทาง, Poppler และ Tesseract ในหน้าต่างโปรแกรม แล้วกดบันทึก

ไฟล์ `.exe` และไฟล์ build ขนาดใหญ่จะอยู่ใน GitHub Releases ไม่อยู่ในประวัติซอร์ส เพื่อให้การอัปเดตซอร์สทำได้เร็วและไม่ติดข้อจำกัดขนาดไฟล์ของ GitHub

## รันจากซอร์ส

ต้องใช้ Python 3.10 ขึ้นไปบน Windows:

```bat
py -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe auto_receive.py
```

หรือเปิด `setup_and_run.bat`

## อัปเดตโปรเจกต์

เมื่อมีเวอร์ชันใหม่ ให้กด **Code > Download ZIP** หรือใช้ Git:

```bat
git pull
```

จากนั้นดาวน์โหลด `.exe` จาก Release ล่าสุดอีกครั้ง หากต้องการใช้เวอร์ชันโปรแกรมที่ build ใหม่

## หมายเหตุ

- ไม่ควรอัปโหลดไฟล์ตั้งค่าที่มี path ของเครื่องหรือข้อมูลการใช้งานจริง
- โปรแกรมจะค้นหาโฟลเดอร์ `poppler` และ `tesseract` ที่อยู่ข้างไฟล์โปรแกรมได้ หากนำไลบรารีมาด้วย
